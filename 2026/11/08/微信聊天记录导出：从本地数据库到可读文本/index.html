使用 WeChatMsg-4x 导出电脑版微信聊天记录

这次实际使用的工具：WeChatMsg-4x

这次导出聊天记录，用的不是 wechat-decrypt，而是 WeChatMsg-4x。它是一个面向 Windows PC 微信 4.0 / 4.1 的本地聊天记录查看、解密与导出项目；本次我们就是通过它读取本人已登录电脑版微信的本地数据，并导出可阅读的聊天记录。

本文只记录处理自己有权访问的账号和数据。数据库密钥、解密数据库、导出的 HTML/CSV/TXT 都含有高度敏感信息，绝不能上传、公开分享或提交到 Git。

WeChatMsg-4x 能做什么

它在本机完成数据处理，主要能力包括：

  • 适配新版 PC 微信 4.x；
  • 检测正在运行且已登录的微信；
  • 提取本地聊天数据库所需的密钥并解密；
  • 在本地还原和浏览聊天记录；
  • 导出 HTML、CSV、TXT 等记录，HTML 还可带图片、表情、语音和视频等媒体。

项目地址：https://github.com/chenanhan230-del/WeChatMsg-4x

使用前准备

  1. 使用 Windows，并保持电脑版微信处于登录状态。
  2. 建议以管理员身份运行终端或图形界面；否则可能无法检测微信进程或读取密钥。
  3. 准备 Python 3.10+，或直接使用项目 Release 提供的可执行文件。
  4. 如手机端的历史消息尚未同步到电脑，先在手机微信中使用“聊天记录迁移与备份 → 迁移到电脑微信”，完成后重启电脑版微信。

不要直接修改微信原始数据目录。WeChatMsg-4x 会将处理结果保存在自己的工作目录中。

常见问题

一直检测不到微信

先确认电脑版微信正在登录，再以管理员身份运行工具。WeChatMsg-4x 专门增加了 4.x 适配层；如果微信版本发生变化，优先查看项目 README、适配说明和 issue。

手机聊天记录没有出现在电脑里

先在手机微信执行“聊天记录迁移与备份 → 迁移到电脑微信”，迁移结束后重启电脑版微信，再重新检测和导出。

数据库已解密，但不知道如何看

可以直接打开 app/DataBase/export/index.html 浏览；若需要查看 SQLite 数据库本身，可用 DB Browser for SQLite 等工具打开解密后的文件。

小结

本次的核心工具是 WeChatMsg-4x。它负责本地检测微信、取密钥、解密、查看与导出；我们只将导出结果用于自己的记录整理。整个流程的底线是：只处理自己的数据、绝不公开密钥与完整聊天记录、导出后做好本地保存和清理。
