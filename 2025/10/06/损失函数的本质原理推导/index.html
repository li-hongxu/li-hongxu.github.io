损失函数的优化之路：从闭式解到梯度下降

深度学习的一核心目标便是拟合，而如何衡量拟合的程度，便是通过损失函数来评价。那么这个过程是如何实现的呢？

简单的线性函数

假设我们拟合的点有明显的线性关系，那么我们可以用

y=ax+by = ax + b y=ax+b

来进行拟合，其中 aaa 和 bbb 是待求的参数。

那如何评价拟合的程度呢？可以通过拟合点距离我们函数的竖直距离来衡量。

很明显，当拟合效果最佳时，所有点都位于函数上，此时每个点的竖直距离为0。

所以，我们可以最小化所有点的竖直距离之和来衡量拟合效果。

很常用的方法是，求出每一个点的竖直距离的平方，然后求和，最终求平均。这个值越小，代表拟合效果越好。

Loss=MSE=1n∑i=1n(yi−y^i)2=1n∑i=1n(yi−(wxi+b))2\text{Loss} = \mathrm{MSE} = \frac{1}{n} \sum_{i=1}^{n} (y_i - \hat{y}_i)^2 = \frac{1}{n} \sum_{i=1}^{n} (y_i - (w x_i + b))^2 Loss=MSE=n1​i=1∑n​(yi​−y^​i​)2=n1​i=1∑n​(yi​−(wxi​+b))2

这样的好处是，不仅反映出整体的拟合情况，而且有固定的衡量标准，即越接近0约好。（如果只用简单的求和，那么会导致当数据量很大时，所求的值也会很大，不利于比较）

要使损失函数最小，只需要求出参数的导数为0时所对应的情况即可。

∂MSE∂a=2n∑i=1n(wxi+b−yi)xi=0\frac{\partial \mathrm{MSE}}{\partial a} = \frac{2}{n} \sum_{i=1}^{n} (w x_i + b - y_i)x_i = 0 ∂a∂MSE​=n2​i=1∑n​(wxi​+b−yi​)xi​=0

∂MSE∂b=2n∑i=1n(wxi+b−yi)=0\frac{\partial \mathrm{MSE}}{\partial b} = \frac{2}{n} \sum_{i=1}^{n} (w x_i + b - y_i) = 0 ∂b∂MSE​=n2​i=1∑n​(wxi​+b−yi​)=0

这样，便能解出针对线性函数的闭式解。

神经网络

对于神经网络来说，损失函数是非线性的，参数数量庞大，且难以通过解析方式直接求得最优解。因此通常采用梯度下降法等数值优化方法，通过迭代不断逼近最优解。

θnew=θold−η⋅∂J(θ)∂θ\theta_{\text{new}} = \theta_{\text{old}} - \eta \cdot \frac{\partial J(\theta)}{\partial \theta} θnew​=θold​−η⋅∂θ∂J(θ)​

其中，η\etaη 是学习率。

这就是梯度下降法的核心思想，即每次沿着梯度的反方向更新参数，直至收敛。

梯度表明在哪里下降最快，学习率表明下降的幅度是多少。

其优化后的坐标为：

at+1=at−η ∇a a_{t+1} = a_t - \eta \, \nabla_a at+1​=at​−η∇a​

bt+1=bt−η ∇ab_{t+1} = b_t - \eta \, \nabla_a bt+1​=bt​−η∇a​

其中，∇a\nabla_a∇a​ 和 ∇b\nabla_b∇b​ 的计算就是损失函数对 aaa 和 bbb 的偏导数。

∇a=∂MSE∂a=2n∑i=1n(wxi+b−yi)xi\nabla_a = \frac{\partial \mathrm{MSE}}{\partial a} = \frac{2}{n} \sum_{i=1}^{n} (w x_i + b - y_i)x_i ∇a​=∂a∂MSE​=n2​i=1∑n​(wxi​+b−yi​)xi​

∇b=∂MSE∂b=2n∑i=1n(wxi+b−yi) \nabla_b = \frac{\partial \mathrm{MSE}}{\partial b} = \frac{2}{n} \sum_{i=1}^{n} (w x_i + b - y_i) ∇b​=∂b∂MSE​=n2​i=1∑n​(wxi​+b−yi​)

这样，我们便可以求出 aaa 和 bbb 的梯度，然后进行更新。

对于碗装损失函数，其最小值找起来相对容易。而对于类似于沟壑这样的损失函数，其最小值找起来需要更多的时间。

总结

  1. 损失函数是衡量模型拟合优劣的标尺，为模型优化提供明确目标。
  2. 简单模型可以计算闭式解，而复杂模型难以计算，只能逼近。
  3. 梯度下降法是沿梯度反方向更新参数，逐步逼近损失函数的最小值。
  4. 无论是解析解还是梯度下降，目的都是找到一组使损失函数最小化的参数，从而实现对数据的最佳拟合。
