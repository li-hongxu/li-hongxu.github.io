隐藏层的作用 — 以真假钞分类为例

隐藏层的作用 — 以真假钞分类为例

什么是深度学习中的隐藏层，他扮演着什么作用？本文以真假钞分类为例，通过一个简单的例子来解释隐藏层的作用。

真假钞分类

我们的数据集包括1372个样本，每个样本包括2个特征，和1个标签

构建单神经元神经网络

这里，我们用Keras来构建一个序列模式神经网络。

核心流程并不复杂，就是定义一个神经网络，然后编译，最后训练。

定义完模型后，开始编译模型，编译是定义“损失函数+优化器+评估指标”的综合过程。

无隐藏层的训练结果

这里，我们使用分类模型决策边界可视化，来查看训练结果。
就是把模型是如何区分不同类别的那条分界线 画出来，让人直观地看到。

背景颜色 = 模型预测某点是 类别 1 的概率。
颜色深的地方，模型更确信这是 1；
颜色浅的地方，模型更确信这是 0。
等高线（contourf）就是不同概率的分层。

从左图可以看到，决策边界是直线。而实际情况是，真假钞票的边界并不是一条直线。

这说明当前模型的预测能力差，并没有学习到真假钞票的特征。

添加隐藏层

这里我们使用一个包含8个神经元的隐藏层。还将输出节点从1更改为2，以获得真钞和假钞概率的两个输出。

可以看到，加入隐藏层后，决策边界变成了曲线。这说明模型已经学习到了真假钞票的特征。

最后也来对比下隐藏层数量对于loss和准确率的影响

可以发现，有隐藏层的模型在训练精度和训练 loss 上明显优于无隐藏层模型。
随着隐藏层数量增加，模型训练达到理想精度的速度更快，训练曲线也更加平滑。然而，增加隐藏层并未显著提升最终准确率。
另外，训练 loss 在隐藏层数量为 1 时达到最低，这表明仅增加隐藏层和神经元数量并不一定提高模型的最终性能，过多的参数可能导致优化更困难或过拟合。

为什么会这样

之所以如此，是因为没有隐藏层时，输入直接连到输出，本质上就是一个逻辑回归，只能学习线性可分的决策边界。

而当加入隐藏层时，它具有非线性激活函数（sigmoid, ReLU, tanh 等），模型就不再是简单的线性变换，而是可以进行非线性映射。

这样模型可以把输入空间映射到一个更高维的特征空间，在这个空间里，原本线性不可分的数据可能就能分开。

具体来说：

  • 对于没有激活函数的模型：

    即便叠加再多的Dense，它依然是

f(x)=Wk(Wk−1(…(W1x+b1)… )+bk−1)+bkf(x) = W_k(W_{k-1}(\dots(W_1 x + b_1)\dots) + b_{k-1}) + b_k f(x)=Wk​(Wk−1​(…(W1​x+b1​)…)+bk−1​)+bk​

实际上依然是：

f(x)=W′x+b′f(x) = W' x + b' f(x)=W′x+b′

依然是一个线性变换

  • 对于有激活函数的模型：

    每一个神经元的输出为：

h=σ(Wx+b)h = \sigma(Wx + b) h=σ(Wx+b)

其中，$\sigma$ 是激活函数

这样，每个每个神经元的输出便是非线性的，多个非线性叠加，就能产生更复杂的形状。

👉 通用近似定理

F(x)=∑j=1mαjσ(wjTx+bj)F(x) = \sum_{j=1}^m \alpha_j \sigma(w_j^T x + b_j) F(x)=j=1∑m​αj​σ(wjT​x+bj​)

对于任意连续函数
𝑓，只要激活函数是非线性的、可微的（比如 sigmoid、ReLU），就存在一个单隐藏层神经网络可以逼近它

总结

  1. 隐藏层的作用是学习数据中的非线性特征。
  2. 隐藏层的神经元越多，模型的表达能力越强，但同时也增加了模型的复杂度和计算量。
  3. 隐藏层能发挥作用，主要是因为其中的激活函数
  4. 在 Jupyter 中训练多个模型时，每个模型在编译前都应使用一个新的 optimizer，否则会报错。原因是 Keras 在 model.compile() 时，会将优化器绑定到模型的可训练变量上，并在内部记录变量状态（如动量、梯度累积），旧的 optimizer 无法识别新模型的变量。
